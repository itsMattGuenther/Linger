# Linger 0.3.1

A bug-fix patch for Windows and Linux. This fixes missing notification sounds
in the Linux AppImage and tightens the composer, settings and message spacing.
Voice remains experimental; its separate-computer and network checks are open.

## What changed since 0.3.0

- **Packaged notification audio:** the AppImage now includes the media plugins
  needed to play chimes. DEB and RPM packages declare the corresponding runtime
  dependencies. Windows EXE and MSI installers explicitly install WebView2 when
  it is missing. Automated audio checks run against all five package formats,
  including the signed release packages, before publication.
- **Send button (#88):** its height now matches the single-line message input
  at every supported interface scale.
- **Attachment menu (#89):** Add opens a compact menu above its button, with
  focus on Add file. The misplaced close button and its immediate tooltip are
  gone. Escape and clicking outside dismiss the menu and return focus.
- **Settings headings (#90):** headings and tabs use consistent title case
  across personal and server settings, including Sound & Voice and Account & App.
- **Message spacing (#92):** lines, paragraphs and sender groups sit closer
  together in both rooms and DMs. Typed line breaks, sender headings and room
  session dividers are preserved.

## Download the app

Install the app on your own computer. Hosts run the separate server image.

| Your computer | Download |
| --- | --- |
| Windows | `Linger_0.3.1_x64-setup.exe` |
| Omarchy, Arch or other Linux | `Linger_0.3.1_amd64.AppImage` |
| Ubuntu, Debian or Mint | `Linger_0.3.1_amd64.deb` |
| Fedora or openSUSE | `Linger-0.3.1-1.x86_64.rpm` |

The `.msi` is an alternative Windows installer. The app uses `.sig` files and
`latest.json` for updates; you do not need to download them yourself. macOS and
ARM desktop installers are not available. The server image supports x86-64 and
ARM64. Windows needs an internet connection to install WebView2 if it is absent.

Windows installers are not code-signed, so SmartScreen may warn. Update packages
have a separate signature checked by Linger; that does not remove the Windows
installer warning. See the
[installation guide](https://github.com/itsMattGuenther/Linger/blob/main/docs/user-guide.md)
for installation and AppImage troubleshooting.

## Updating

**Existing clients:** open Settings → Account & App → Updates and check for
updates, or close Linger and install the new download. Keep your account and app
data. An AppImage is replaced by the new executable. Run the new AppImage once
to refresh its application-menu entry; if your system needs the documented
graphics option, use it with the new filename too.

**Hosts:** there are no database migrations or wire-format changes since
0.3.0. Back up your server data first. If your Compose file pins a version,
change its server image to `ghcr.io/itsmattguenther/linger:0.3.1`. From the
directory containing your existing Compose file:

```bash
docker compose --profile voice pull
docker compose --profile voice up -d
docker compose --profile voice ps
docker compose logs --since=2m linger coturn
```

For text-only hosting, omit `--profile voice` and `coturn` from the log command.
Keep your existing settings and data volume; do not run `down -v`. See the
[host guide](https://github.com/itsMattGuenther/Linger/blob/main/docs/host-guide.md#updating-the-server)
for backup and deployment details.

## Testing limits

Automated package tests check real-time audio rendering on Windows and record
Linux output through a virtual speaker. They do not prove what a person hears
through their physical speakers or headphones. Device changes, voice across
separate networks and the remaining
[release checks](https://github.com/itsMattGuenther/Linger/blob/main/TASKS.md#release-checks--desktop-and-real-world-evidence)
still need their stated evidence.
