# Linger 0.3.4

Fixes the bugs reported after 0.3.3: typing and sending in the composer, the
Linux window on Omarchy and NVIDIA, the voice bar, and a round of layout
polish. The server gains limits on export and video processing. Update the
server too for those two.

## Messaging

- Typing keeps up with the keys in the composer on Omarchy (#127).
- Sending no longer waits on the server: the message shows at once, the box
  clears, and the "Sending…" line under the input is gone (#128, #129).
- Hovering a message shows its actions button and changes nothing else about
  the message's size or position (#139).
- Room and DM headers show the name and topic only, without the list of who is
  in them. Who is in a room is on the rail and in Who's Around (#145; SPEC §4.1
  changed).
- The Add button beside the message box is centered on the input and Send, with
  even space either side (#146).

## Voice

- Voice names sit centered, and talking no longer changes the voice bar's
  height (#137).
- A talking name is marked by turning it over onto its own color (#138).
- Voice control tooltips show whole, including when the bar is collapsed (#140).
- Joining voice no longer flashes a half-built bar or makes the conversation
  flicker, and keeps your place if you had scrolled up (#141, #142).

## Panels and the rail

- Opening server options, a profile or voice options with the mouse no longer
  highlights the close button or shows its tooltip. Keyboard use is unchanged
  (#143).
- Every "more options" button (server, Who's Around, message actions) draws the
  same three dots, level with the text beside it (#144).
- The dot before the server name is gone, and the occupancy dots beside rooms
  and DMs are centered on the name (#164).

## Linux desktop

- No GTK title bar on Hyprland / Omarchy (#130).
- The app no longer closes on launch with `Error 71` on NVIDIA + Wayland:
  startup sets `__NV_DISABLE_EXPLICIT_SYNC=1` unless it is already set. An
  explicit `0` is kept (#135).

## Server

- Video uploads: `ffprobe` gets 15 seconds and the poster frame 30, after which
  the tool is killed and the file is stored without a poster, as on a server
  without ffmpeg (#152).
- Exports build one at a time across the whole server; others wait as `queued`,
  which the app already shows as "Building your archive…" (#151).
- The architecture doc and host guide say that on the S3 backend an export
  downloads the member's files to the server's disk while it builds (#153).

## Install or update

Use the in-app update action. Windows users should keep the same installer
format (`.exe` or `.msi`) when upgrading. Linux packages are available as
`.AppImage`, `.deb` and `.rpm`. Windows installers are updater-signed, not
Authenticode-signed; SmartScreen may still warn about an unfamiliar app.

Server image: `ghcr.io/itsmattguenther/linger:0.3.4` (amd64 and arm64). No
protocol changes break older clients or servers: a long `queued` export is
still a `queued` export.
