# Linger 0.4.1: voice through the server

Voice can now go through your server: everybody sends their voice once, and
the server passes it on to the others, so a room of twenty can talk at once.
The old way is still there, one switch away. This release also fixes chat
windows opening white on Windows, and builds the follow-ups decided after
0.4.0.

Hosts: **update the server.** Voice through the server needs the 0.4.1 server
and two lines in `compose.yaml` (below). The 0.4.1 server also stops telling
anyone who is in a DM with whom. The 0.4.1 app works with a 0.4.0 server, and
the other way round; voice then goes the old way.

## Windows: conversations open again (#205)

- In 0.4.0 on Windows, opening a room, Settings, Search or Media could leave a
  white window that couldn't be clicked or moved. They open and draw again.
  The Windows check that runs on every change now opens Settings and a chat
  window and looks at them.

## Voice through the server (#197)

- On a server whose host has turned it on, your voice goes to the server once
  and it passes it on to everyone else in the room, up to 25 people. Before,
  everybody sent their voice to everybody, which stops working past about ten.
- **The old way stays, for now.** **Settings → Sound & Voice → Voice through the
  server** turns it off and goes straight to each person, as in 0.4.0. If anybody
  in a room has it off, or is on an older Linger, the whole room goes the old
  way, so everybody can always hear everybody. It takes effect the next time you
  join voice.
- If the connection to the server drops, Linger tries again by itself after a
  few seconds.
- The server passes voice along and keeps none of it. It's on the host's
  machine, so the host *could* listen, the same way they could read messages.

## Privacy: being in a DM

- Being in a DM now shows as **around** to everybody, the DM's own people
  included. Nobody sees that you're DMing, let alone with whom. (0.4.0 showed
  the people.) This needs the 0.4.1 server.

## The list

- **Arrival cards.** When somebody comes into a room, a small card says so
  ("Callie came into #general") and goes by itself. It never takes the cursor.
  None from a Quiet server or in quiet hours, and at most one a minute per
  person. Turn them off in **Settings → Notifications → Arrivals**.
- **The door chime**, a soft ding-dong when somebody arrives, is off until you
  turn it on in **Settings → Sound & Voice**. At most once every five minutes
  per person, and quiet in quiet hours. Everybody's own entrance sound will
  replace it later.
- **Empty places say so**: no rooms yet (the host gets **Make the first room**),
  nobody else here, no search results, nothing in Media.
- **Many rooms fold.** Past eight rooms on a server, the ones with nobody in them
  and nothing new fold under **More rooms**.
- **One server being down no longer holds up the others.** The list opens with
  the ones that answer, and the one that's down stays signed in, shows as
  "Can't reach … Still trying." at the foot of the list with **Try now**, and
  joins by itself when it's back. If none answers, Linger says so and keeps
  trying, rather than asking you to sign in again.

## Conversations

- **What you were typing is kept** per conversation, across closing its tab and
  restarting Linger, on this computer only. Sending clears it.
- **Pin a message** from its **⋯** menu (Unpin, too). A pinned message has a
  small pin beside it, and pinned files never expire.
- **Clicking a desktop notification opens that conversation, at the message.**
  On Windows this works while the notification is on screen; from the
  notification center, it just brings Linger up.

## Voice keys

- **Choose your push-to-talk key** in **Settings → Sound & Voice → Talk key**.
  It starts on **Right Ctrl**, so the Ctrl shortcuts (Ctrl+Tab, Ctrl+K, …) no
  longer open your microphone. Push-to-talk is still off unless you turn it on;
  an open microphone is the default.

## The previous look, one more release

The 0.4.0 notes said the previous client would go in this release. It stays
one more, while the new voice is tried: start Linger with `LINGER_CLASSIC=1`
(on Linux, `LINGER_CLASSIC=1 linger-client`). It shares your sign-ins and
servers, and it doesn't have anything new above.

## Install or update

Use the in-app update: **Update…** at the foot of the list, or Settings →
Account & App → Updates. Windows users should keep the same installer format
(`.exe` or `.msi`) when upgrading. Linux packages are `.AppImage`, `.deb` and
`.rpm`; on Omarchy or Arch, Linger updates with your system. Windows
installers are updater-signed, not Authenticode-signed; SmartScreen may still
warn about an unfamiliar app.

Server image: `ghcr.io/itsmattguenther/linger:0.4.1` (amd64 and arm64). To
update: `docker compose pull && docker compose up -d` (add `--profile voice`
to both if you run the voice relay). No database changes.

To turn on voice through the server, in the `linger` service of your
`compose.yaml` (a `compose.yaml` from before 0.4.1 has neither line):

```yaml
    environment:
      # ...what's there already...
      LINGER_VOICE_ADDRESS: 203.0.113.7   # your server's public IP address
    ports:
      - "3479:3479/udp"
```

Find the address with `curl -4 https://api.ipify.org` on the server, allow
**UDP 3479** in your cloud firewall (and `ufw allow 3479/udp` if the machine
runs its own), then `docker compose up -d`. `docker compose logs linger` says
`voice forwarding is on`. No DNS changes: the address is an IP, not a name.
The host guide has the details, under "Voice for bigger groups".

## Checks on installed clients

Record OS, package type, previous and new version, and interface size with
any failure. Use made-up messages, and keep private conversations out of
screenshots.

1. Windows: update from 0.4.0, then open a room, Settings, Search and Media.
   Each window draws and can be moved and closed.
2. Voice through the server with one other person, then with everybody you can
   gather, on different networks. Everybody hears everybody; mute, deafen and
   leave work; somebody leaving and rejoining is heard again.
3. One person turns **Voice through the server** off and rejoins: the room still
   works, the old way.
4. Somebody comes into a room: a card says so and goes by itself. Turn on the
   door chime and check it plays once, not every time they hop rooms.
5. Get mentioned while Linger is in the background, click the notification: the
   conversation opens at that message (Linux and Windows).
6. Turn on push-to-talk, pick a key, and talk with it. Ctrl+K and Ctrl+Tab don't
   open the microphone.
7. Type half a message, close the tab, restart Linger, open the conversation:
   the half message is there.
8. Pin a message, and see it in Media's pinned files.
9. With two servers saved, stop one (or cut its network), start Linger: the
   other opens straight away, and the stopped one joins when it's back.
