# Linger v0.2.0 — a more comfortable place to hang out

An early testing release for Windows and Linux. The Console redesign and
onboarding fixes are ready for another round with friends. Voice still needs
the planned four-person, separate-network acceptance test; this release does
not claim that check is complete.

## Download the app

Install this on your own computer, not the VPS.

| Your computer | Download |
|---|---|
| Windows | The `x64-setup.exe` |
| Omarchy, Arch or other Linux | The `amd64.AppImage` |
| Ubuntu, Debian or Mint | The `amd64.deb` |
| Fedora or openSUSE | The `x86_64.rpm` |

The `.msi` is an alternative Windows installer. Skip `.sig`, `latest.json`
and source archives; the app uses the update files itself. macOS and ARM
desktop installers are not available.

**Windows installers are not code-signed.** SmartScreen may warn. Only
continue if you trust this official download; choose More info → Run anyway
if you decide to proceed. Update packages have a separate cryptographic
signature that Linger checks; that does not remove Windows' warning.

[Installation and AppImage troubleshooting](https://github.com/itsMattGuenther/Linger/blob/main/docs/user-guide.md)
cover running the download. New members need an **invite link from their
host**, not just the server address.

## What's changed since v0.1.0

- **A readable, responsive Console.** Larger default text, 100–200% interface
  size in Settings → Appearance, adjustable side panels, and collapsible
  navigation and People panels when space is tight. One comfortable layout
  replaces the old density modes. Includes browser checks for 4K at 125%
  desktop scaling; comfort on real displays still needs your feedback.
- **Clearer controls.** Consistent buttons, compact labelled toolbar icons,
  member popouts, personal settings by your name and server management in the
  selected server's menu. Voice names are more prominent; participant volume
  opens on demand. Call controls stay reachable while you browse elsewhere.
- **Small, satisfying details.** The chosen porch artwork, private name/status
  previews, reaction feedback that respects reduced motion, full-image media
  tiles, and clear Star confirmations.
- **Voice state and sound.** Shared microphone state and deafen. Deafen mutes
  your microphone and incoming voice, then restores your previous microphone
  setting when turned off. Twelve related notification cues with category
  switches, master silence and quiet hours. Ordinary room-message sounds
  remain off by default.
- **First-time setup fixes.** The bundled voice relay starts without the
  rejected coturn flag. Host instructions cover Docker, DNS, firewalls,
  storage sizing and checking the relay. User instructions explain downloads,
  invite links and updates.
- **Client fixes.** Centered, fitted image previews; recoverable file-download
  errors; temporary Knock feedback; consistent porch app icons; an opt-in
  native Wayland launch for Linux dictation testing. File downloads still use
  the browser. The default AppImage input path may need clipboard dictation.

No avatars, unread counts, telemetry or new runtime frontend dependencies.

## Updating

**Hosts:** back up your server data first. From the directory containing your
existing `compose.yaml`, update the server and relay:

```bash
docker compose --profile voice pull
docker compose --profile voice up -d
docker compose --profile voice ps
docker compose logs --since=2m linger coturn
```

Keep your existing settings and data volume. Do not run `down -v`. These
commands use the image configured in your Compose file; if you pinned an
older server tag, change it to `ghcr.io/matthewguenther/linger:0.2.0` first.
Update the server before testing shared mute/deafen state with new clients.
If your existing coturn command still contains `--no-dtls`, remove that flag
before restarting; pulling images does not update your Compose file.
For text-only hosting, omit `--profile voice` and `coturn` from the log command.
See the [host guide](https://github.com/itsMattGuenther/Linger/blob/main/docs/host-guide.md#updating-the-server)
for backup and deployment details.

**Existing clients:** use the update check in Settings (Account & app in the
new layout), or close Linger and install the new download. Keep your account
and app data. An AppImage is replaced by the new executable; it is not a
separate installer. If your system needs the documented graphics workaround,
use it with the new filename too.

## What still needs testing

Packaged Windows/Omarchy rendering and high-DPI comfort; a real v0.1.0 →
v0.2.0 update preserving sign-ins; a friend finding Settings, sharing a file
and joining voice unaided; and real sound/device behavior. The four-person,
four-network, one-hour voice check and the separate relay/device checks remain
open. Two-person voice success and automated tests do not replace them.

Use [the existing release checklist](https://github.com/itsMattGuenther/Linger/blob/main/TASKS.md#human-checks--things-only-you-can-do)
to record results, without posting passwords, setup tokens or private messages.
