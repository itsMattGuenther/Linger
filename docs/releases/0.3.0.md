# Linger 0.3.0

An early testing release for Windows and Linux, collecting the desktop and UI
fixes since 0.2.0. Voice remains experimental: the planned four-person,
four-network, one-hour check is still open.

## What changed since 0.2.0

- **Linux AppImage startup:** closing the launching terminal no longer closes
  Linger. First launch adds an application-menu entry and carries forward the
  documented graphics or Wayland option used for that launch.
- **Composer controls:** the plus button opens Add file, the smile button inserts
  ordinary Unicode emoji at the cursor, and Send remains the primary action.
- **Notification sound:** a real click unlocks chimes, Preview can play even when
  notifications are silenced, and quiet hours start off for fresh preferences.
  Existing saved preferences remain respected.
- **Navigation:** long server, room and DM names wrap instead of truncating or
  opening a horizontal scrollbar. Search uses the same DM names as the rail.
- **UI corrections:** message actions stay clear of the text; Search, Media and
  Settings share headings and Close controls; sound switches line up. Ordinary
  messages use the four bundled sans-serif faces. Older non-sans message choices
  fall back to the reading face; all twelve name fonts remain available.
- **Accurate links and copy:** remaining project and package links use the current
  GitHub owner. Voice settings no longer claim that nobody can record a call.

## Download the app

Install the app on your own computer. Hosts run the separate server image.

| Your computer | Download |
| --- | --- |
| Windows | `Linger_0.3.0_x64-setup.exe` |
| Omarchy, Arch or other Linux | `Linger_0.3.0_amd64.AppImage` |
| Ubuntu, Debian or Mint | `Linger_0.3.0_amd64.deb` |
| Fedora or openSUSE | `Linger-0.3.0-1.x86_64.rpm` |

The `.msi` is an alternative Windows installer. The app uses `.sig` files and
`latest.json` for updates; you do not need to download them yourself. macOS and
ARM desktop installers are not available. The server image supports x86-64 and
ARM64.

Windows installers are not code-signed, so SmartScreen may warn. Update packages
have a separate signature checked by Linger; that does not remove the Windows
installer warning. See the
[installation guide](https://github.com/itsMattGuenther/Linger/blob/main/docs/user-guide.md)
for installation and AppImage troubleshooting.

## Updating

**Existing clients:** after this release is published, open Settings → Account
& app and check for updates, or close Linger and install the new download. Keep
your account and app data. An AppImage is replaced by the new executable. Run
the new AppImage once to refresh its application-menu entry; if your system
needs the documented graphics option, use it with the new filename too.

**Hosts:** back up your server data first. If your Compose file pins a version,
change its server image to `ghcr.io/itsmattguenther/linger:0.3.0`. If it still
names the old `matthewguenther` owner, correct that image path before pulling.
From the directory containing your existing Compose file:

```bash
docker compose --profile voice pull
docker compose --profile voice up -d
docker compose --profile voice ps
docker compose logs --since=2m linger coturn
```

For text-only hosting, omit `--profile voice` and `coturn` from the log command.
Keep your existing settings and data volume; do not run `down -v`. There are no
database migrations or wire-format changes since 0.2.0. See the
[host guide](https://github.com/itsMattGuenther/Linger/blob/main/docs/host-guide.md#updating-the-server)
for backup and deployment details.

## What still needs testing

An installed 0.2.0 client updating to 0.3.0 on a separate computer while keeping
its sign-ins; packaged Windows/Linux rendering and large-text comfort; a friend
finding Settings, sharing a file and joining voice without instructions; physical
audio devices and listening; and voice across separate networks, including relay
use. Automated checks do not close these acceptance checks.

Record results in the
[existing release checklist](https://github.com/itsMattGuenther/Linger/blob/main/TASKS.md#release-checks--desktop-and-real-world-evidence).
Do not include passwords, setup tokens or private messages in reports.
