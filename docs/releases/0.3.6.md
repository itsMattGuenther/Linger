# Linger 0.3.6

Omarchy and Arch get their own package, which keeps typing and scrolling fast
and updates with the rest of the system. The AppImage no longer crashes on its
first launch on NVIDIA + Wayland machines, and quiet hours can be moved and
leave call controls alone. This is an app-only release: the server is
unchanged, so hosts do not need to update.

## Omarchy and Arch

- **A Linger package for Omarchy and Arch.** Set it up once and Linger then
  updates with your system: Update in the Omarchy menu, or `sudo pacman -Syu`.
  It uses the system's WebKit, which can draw with the graphics card, so fast
  typing and scrolling keep up on machines where the AppImage lags (#169, #188).
  One-time setup:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/itsMattGuenther/Linger/main/packaging/arch/setup.sh | bash
  ```

  The script checks Linger's signing key by its fingerprint before trusting it,
  adds Linger's repository to pacman, installs Linger, and removes the menu
  entry an old AppImage left behind. The [user guide](https://github.com/itsMattGuenther/Linger/blob/v0.3.6/docs/user-guide.md#arch-and-omarchy)
  shows each step. You stay signed in when moving from the AppImage.
- With the package, Settings → Account & App → Updates says updates come with
  your system, instead of offering to install them itself.

## Linux AppImage

- **No more crash on the first launch after updating** on NVIDIA + Wayland
  machines. 0.3.5 turned on WebKit's GPU drawing path, which the AppImage's
  bundled WebKit can't use on that hardware; the AppImage now keeps it off, as
  0.3.4 did (#187). The `.deb`, `.rpm` and Arch package use the system's WebKit
  and keep it on.
- A crash on the GPU path is now remembered per WebKit version, so a WebKit
  update gets a fresh try, and the AppImage's crashes can't slow down a package
  install on the same computer.

## Sound

- **Quiet hours can be moved** (#185). Turn them on and choose **Quiet from** and
  **Quiet until**, in half-hour steps: 21:00 to 06:00 for an early night, 02:00
  to 12:00 for a late one.
- **Quiet hours silence notifications, not your call** (#186). DM, room and
  knock chimes go quiet; mute, deafen and voice join/leave sounds still play.
  Voice itself was never affected.

## Reporting problems

- **Issue forms** on GitHub ask for what a bug report needs, and remind you to
  leave private things out.
- **Skills for coding agents** such as Claude Code or Codex (#147):
  `linger-report` looks into a problem, checks whether it's known or already
  fixed, and drafts an issue with nothing private in it; `linger-contribute`
  makes a fix and opens a pull request the project's way. Neither sends
  anything without your yes. On the Arch package, `linger-agent-skills` links
  them into your agents; elsewhere, see [`agents/`](https://github.com/itsMattGuenther/Linger/tree/v0.3.6/agents).

## Install or update

Use the in-app update action. Windows users should keep the same installer
format (`.exe` or `.msi`) when upgrading. Linux packages are available as
`.AppImage`, `.deb` and `.rpm`; on Omarchy or Arch, use the package above
instead. Windows installers are updater-signed, not Authenticode-signed;
SmartScreen may still warn about an unfamiliar app.

Server image: `ghcr.io/itsmattguenther/linger:0.3.6` (amd64 and arm64) is the
same server as 0.3.5. No protocol changes; older apps and servers keep working.

## Checks on installed clients

Record OS, package type, previous/new version and interface size with any failure.
Use synthetic messages and avoid private conversations in screenshots.

1. On Omarchy, run the one-time setup. Linger installs, opens from the menu with
   one Linger entry, stays signed in, and fast typing and scrolling keep up.
   Settings → Updates says updates come with your system. A later release
   arrives through Omarchy's Update.
2. Update an AppImage from 0.3.5 on an NVIDIA + Wayland machine: the first launch
   after updating opens, with no crash.
3. Turn quiet hours on, move them to include now, and check: a DM makes no
   sound; mute, deafen and joining voice still do. Reopen Settings: the times are
   kept.
4. With `linger-agent-skills` (Arch package) or `agents/link-skills.sh`, your
   agent finds the `linger-report` skill.
