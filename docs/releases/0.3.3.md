# Linger 0.3.3

Fixes the bugs reported after 0.3.2 and completes the requested voice-volume
and reading-position enhancements. All changes are tracked in
[PR #125](https://github.com/itsMattGuenther/Linger/pull/125).

- Linux startup defaults the narrow GBM workaround and selects native Wayland
  on Wayland desktops. Explicit backend and GBM overrides remain available
  (#114, #122).
- Deleted replies no longer display their quote. Quotes appear after the
  sender's name, including consecutive messages from the same person (#115, #116).
- Enter clears the composer immediately while sending. Later typing is preserved;
  failed messages can be recovered without replacing a newer draft (#117).
- Knock prevents duplicate submissions and shows pending/failure feedback.
  Requests, including authentication renewal, have a deadline so a stalled request
  cannot silently block later interaction (#118).
- A fresh connection sees the existing voice participants in rooms it can access,
  without joining voice. Update the server too for this fix (#119).
- Per-person voice volume is remembered on this device for each server, across
  rejoining and restarting. Multiple sessions for the same person share the level (#120).
- Speaking emphasis sits directly on the person's name. The visible “you” suffix
  is removed, while the accessible label still identifies you (#121).
- Rooms and DMs open at your saved reading position when newer messages exist.
  Caught-up conversations open at the newest message. Search still opens its
  chosen result; the catch-up header control and divider are removed (#123).
- Voice failure labels stay centered below the name without wrapping, with a
  clearer strike through the name (#124).

## Install or update

Use the in-app update action once published. Windows users should keep the same
installer format (`.exe` or `.msi`) when upgrading. Linux packages are available
as `.AppImage`, `.deb` and `.rpm`. Windows installers are updater-signed, not
Authenticode-signed; SmartScreen may still warn about an unfamiliar app.

Server image: `ghcr.io/itsmattguenther/linger:0.3.3` (amd64 and arm64).
The voice roster snapshot is an optional protocol addition; older clients and
servers remain compatible. Voice volume stays local to the client.

## Checks on installed clients

Record OS, package type, previous/new version and interface size with any failure.
Use synthetic messages and avoid private conversations in screenshots.

1. Update from 0.3.2. On the affected Linux machine, launch normally and verify
   there is no GBM abort. On Wayland, dictate using the usual physical shortcut
   and confirm the words arrive unchanged. Explicit X11 still needs the clipboard
   workaround described in the user guide.
2. Send in a room and DM, immediately type another draft, then check both texts.
   Knock twice after the first confirmation resets, then send again.
3. Reply to a message, verify name/quote/body order, and delete the reply. Its
   quote should disappear while the original message remains.
4. Join from two computers. A newly connected third client should see the voice
   participants before joining. Check speaking/failure labels and rejoin after
   changing somebody's volume; restart and confirm the level is remembered.
5. Leave a room and DM partway through reading. Add messages from another client,
   return, and verify the saved position. Search should still open the exact
   result; Back to newest should reach the end.

Automated input checks use synthetic typing and paste, not a spoken recording.
Native package checks use synthetic people and responses, not a live server.
Physical listening, real graphics on affected hardware, and separate-machine/
network release checks remain open until their stated evidence exists. Issues
#81 and #101 remain deferred. M12 remains the current milestone.
