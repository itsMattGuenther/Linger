# 0.3.2 two-person smoke check

Allow roughly 10–15 minutes on Linux and Windows. This is a testing release for
the existing two-person group, not a claim that all release-readiness checks pass.

1. **Update first.** From the currently installed version, use the client's own
   update action. Confirm Settings reports 0.3.2, saved servers remain available,
   and the app restarts. On Windows confirm there is no new duplicate desktop
   shortcut (#108). Keep any pre-existing duplicates for comparison: this fix
   prevents new ones; it does not remove customized shortcuts.
2. **Navigation.** Resize the window and the left pane, including a short window.
   Try 100%, your usual interface size and 200%. Long names should wrap, there
   should be no sideways scrollbar, and Media/Search should remain reachable (#100).
3. **Messages.** Send consecutive messages from the same person in a room and DM.
   Check compact spacing, multiline text and message actions. There should be
   no colored bar alongside each message (#93).
4. **Controls and reactions.** Open Add and Server options by mouse, then keyboard.
   Mouse opening should not show a bright ring; keyboard focus should remain
   visible (#96). Confirm “Join Voice” (#97). Add/remove a reaction: its outline
   should stay quiet (#98), and its tooltip should match the app and list the
   people who reacted (#99). Try both themes.
5. **Listen.** Preview the DM and knock sounds, then exchange an actual DM and
   knock. Try the first sound after sitting idle too. Listen for a clean DM onset
   and both knock taps (#94, #95). Automated virtual-speaker checks cannot replace
   this listening check on your hardware.
6. **Quick sanity check.** Exchange a room message, reconnect one client, join and
   leave voice, and reopen the app. Check for missing/duplicate messages and that
   voice controls still work. Real-network voice acceptance remains a separate task.

Report failures against the original issue, with OS, installer format, previous
version, 0.3.2, interface size and exact steps. Reopen the issue if necessary;
an issue closed by a merged PR is not proof that your machine passed.
