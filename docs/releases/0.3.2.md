# Linger 0.3.2

Patch release for the Windows/Linux issues reported after 0.3.1.

- Compact message spacing in rooms and DMs; removed per-message colored bars (#93, PR #102).
- Clean notification onset and both knock taps, including after idle (#94, #95, PR #103).
- Restrained keyboard focus without bright pointer-opened outlines (#96, PR #105).
- Consistent “Join Voice” label (#97, PR #106).
- Quieter reaction chips and app-styled tooltips listing the people who reacted (#98, #99, PR #107, PR #109).
- Navigation stays inside its scroll area on Linux and Windows (#100, PR #110).
- Windows MSI upgrades preserve customized desktop shortcuts instead of creating an additional default shortcut (#108, PR #111). Existing duplicate shortcuts are not removed.

The fixes were integrated and tested together in PR #112. Tests now include
native Windows/WebView2 and Linux/WebKitGTK navigation checks alongside package
audio and installer checks. CI selects affected test groups and retains browser
failure evidence. This does not replace physical listening and real-network
voice checks, which remain open.

## Install or update

Existing clients can use the in-app update action after this release is published.
Windows: choose the `.exe` installer for a normal install, or keep using `.msi`
if that is how you installed the app. Keep the same installer format when testing
an upgrade. Windows installers are updater-signed, not Authenticode-signed;
SmartScreen may still warn about an unfamiliar app.

Linux: use the `.AppImage`, `.deb`, or `.rpm` for your distribution. DEB/RPM
updates use the system package installer and may request administrator access.
The Linux packages include or require the Web Audio playback runtime.

Server image: `ghcr.io/itsmattguenther/linger:0.3.2` (amd64 and arm64).

Start with the [two-person testing checklist](https://github.com/itsMattGuenther/Linger/blob/v0.3.2/docs/releases/0.3.2-testing.md).
It covers the actual update, navigation, message spacing, controls, reactions
and listening checks. If a problem remains, reopen its original issue with your
OS, package type, old/new version, interface size and reproduction steps.
