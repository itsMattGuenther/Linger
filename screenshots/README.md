The `1920`, `1280`, `1100` and `760` images show wide, ordinary, default and
minimum desktop windows. Light-theme versions are alongside the dark ones.
All use the single comfortable layout; density modes have been removed.

The 4K files are 3840×2160 at desktop 100% scaling, with the specified app
scale. View them at actual size to compare text, not shrunk to fit a browser.
The `desktop125` files simulate your 125% desktop scaling. HiDPI browser
checks cover 100%, 125% and 200% desktop scaling at the same physical resolution.

These are the running production UI components with fictional people and local
test responses, captured in Chromium. They are not a recording of a live server
or proof of native audio, Windows rendering, or a packaged desktop build.
